What it is

Panda Federation Tools is an index of pay-per-result Apify Actors wrapped as Model Context Protocol (MCP) servers. Prefer one focused domain server (3–15 tools) instead of loading every tool at once.

  • Built on official and public datasets (no private scrapes of paywalled apps).
  • Each call runs on your Apify account with a spend cap (run_max_charge_usd).
  • MCP packages are MIT; Actors bill pay-per-result on Apify.

FAQ

Do I pay a subscription?

No product subscription. Actors are pay per result on Apify. Empty runs are not charged per result; each call can set a hard spend cap.

Why four servers instead of one mega-server?

Focused servers stay in the 3–15 tool band, which scores better for Tool Definition Quality / Glama coherence. The umbrella package still exists for older configs.

Where does the data come from?

Official and public sources such as Crossref, OpenAlex, PubMed, Grants.gov, USAspending, SEC EDGAR, IRS nonprofit filings, NPI, FMCSA, EU TED, DNS/RDAP, and public web pages — depending on the tool.

Is the code open source?

Yes. The MCP servers are MIT on GitHub and PyPI. The Apify Actors bill separately for compute and results.
